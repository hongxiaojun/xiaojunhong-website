## 省时摘要

特斯拉成为燃油车对手，不是因为造了「更好的电动车」，而是因为它让「解雇油车」在一种常见处境里不再等于降级。

心智上，它是燃油豪华最主要的征服者。量上，尤其在中国，把油车从新车默认选项里挤走的，是整条新能源战线。JTBD 解释的是为什么有人愿意换；政策、电池成本和工厂，解释的是为什么换得成百万辆。

三个必须拆开的工作：雇性能豪华、雇省心的日常车、雇一辆被允许拥有的车。用第一份的身份故事去解释第二份的销量，是最容易写漂亮、也最不该犯的错。

---

很多人第一次听到「特斯拉颠覆了燃油车」，脑子里会出现两种快捷解释。一种是技术的：电机比发动机好。一种是环保的：世界要减排。两种都沾边，但都解释不了几件扎眼的事实：

- 更早的电动车为什么失败？
- 为什么特斯拉先造十万美元的跑车，而不是先造一辆便宜代步车？
- 为什么有人开过之后不愿再开回油车，另一些人却宁可选插混、增程？
- 在中国，把燃油车销量挖走最多的，为什么常常不是特斯拉，而是比亚迪？

要讲清这些，得换一个提问方式。不要问「电动车比燃油车好在哪」，问：

**人们雇一辆车，到底来干什么？**

这就是 Jobs to Be Done，简称 JTBD，中文常译成「待完成的工作」。下面先把这个镜头讲清楚，再用它看特斯拉。镜头本身有边界：它很擅长解释「为什么有人愿意换」，解释不了「为什么换得成百万辆」。后面会把这条界线画出来。否则一个好理论，会变成全能故事。

## 一、JTBD 到底在说什么

### 1. 顾客不买产品，他们「雇」产品来干活

哈佛商学院教授克莱顿·克里斯坦森（Clayton Christensen）有一句被引用到发腻、但仍然准确的话：

> 顾客不是在买产品或服务，他们是在「雇佣」它来完成一项工作。

「工作」在这里不是职业，是：**一个人在特定处境里，想取得的进步。**

注意三个词。

- **进步**：他要往前走一步，不是要一个功能列表。买电钻的人要的不是电钻，是墙上的洞；更往里说，是把镜子挂上、让房间看起来像样。
- **处境**：同一项进步，周一早上的通勤和周日全家出游，完全不是同一份工作。离开处境谈需求，需求会变得空洞——「我要一辆好车」几乎能套在任何人头上，对企业毫无指导。
- **雇佣 / 解雇**：选新方案，等于雇它来干这份活；同时往往要解雇旧方案。转换之所以难，是因为解雇有成本。

所以 JTBD 真正问的不是「目标用户是谁」，而是：**在那种情况下，他要完成什么，当时还有哪些候选方案可以雇。**

### 2. 奶昔的故事：为什么「竞品」经常不是你以为的那个

克里斯坦森做过一个后来成为教材的研究。某快餐连锁想提高奶昔销量，按常规办法改进：口味、包装、目标人群（男性？下午茶？健康？）。改了半天，销量不动。

后来他们换了问法：人们**什么时候**买奶昔，买来**干什么**。

结果一大半发生在早上九点前。上班族开车出门，路途长、无聊、一只手要握方向盘，十点左右还会饿。奶昔被雇来干的活是：

- 让漫长通勤不那么空
- 用细吸管慢慢喝，刚好撑过一上午
- 单手、不洒、不碎屑

它真正的对手不是另一杯奶昔。是香蕉（吃得太快、弄得手上黏）、甜甜圈（碎屑、一会儿又饿）、咖啡、甚至「无聊本身」。奶昔在那份工作上赢了：稠、慢、不脏、能撑到十点。

这件事把 JTBD 最反直觉的一点说透了：

**竞争发生在「同一份工作」上，不发生在「同一个品类」上。**

看汽车，如果只在「汽车 vs 汽车」里打转，你会漏掉加油站、4S 店、第二辆车、打车、再忍一年、插混。这些都可能是当时真正的候选。

### 3. 一份工作通常有三层

同一份雇佣，往往同时有：

| 层 | 问的是 | 买车时的样子 |
|---|---|---|
| 功能 | 这件事能不能办成 | 准时到、能载人、能跑长途、别抛锚 |
| 情感 | 办成的时候我是什么感觉 | 省心、爽、有掌控、少一点愧疚和焦虑 |
| 社会 | 别人会怎么看我 | 这辆车让人读懂「我是谁」 |

三层都真实。常见错误是只看见功能（A 到 B），或者反过来，把情感和社会讲成全部原因。特斯拉的故事里，两头都有人讲过头。

### 4. 转换不是「变心」，是四股力同时翻面

鲍勃·莫埃斯塔（Bob Moesta）把「解雇旧的、雇佣新的」写成四股力。这是 JTBD 里最能用的一张图：

```
        推力（现状开始难受）          拉力（新方案让人想要）
                \                        /
                 \                      /
                  解雇旧方案 / 雇佣新方案
                 /                      \
                /                        \
        习惯（旧方案的黏性）          焦虑（新方案的害怕）
```

左边两股把人推向改变：现在的方案越来越难受，新的越来越想要。右边两股把人拉住：新的让人怕，旧的已经长进生活。

只把新产品做得「更好」，往往不够。早期电动车有环保的拉力，焦虑和习惯纹丝不动，所以替代发生不了。特斯拉花十年做的，很大一部分不是把车造快，而是把右下角两股阻力拆掉。

还有一个方法上的纪律，后面会反复用到：**不要按人群标签切需求。** 同龄、同收入的两个人，不会买同一辆车。JTBD 禁止的就是「一线新精英」「科技爱好者」这种人口统计切片。它要的是处境：有没有车位、是不是唯一用车、这次是换购还是增购、牌照怎么来。

### 5. 它和「颠覆式创新」不是一回事

克里斯坦森还有另一套更出名的理论：破坏性创新——从低端或非消费市场进来，一开始更差更便宜，再往上打。

他本人多次说过：特斯拉**不是**这种破坏。它从高端往下走，是把已经很好的东西做得更好，属于维持性创新。特斯拉很懂待完成的工作，产品也强，但按破坏理论的定义，它不合格。

这一点必须先记住。后面用 JTBD 讲特斯拉，不是为了强行给它戴「颠覆」的帽子。JTBD 不管你从哪一层进来，只问：用户在这个处境里，能不能把旧方案解雇。能，就是对手。

## 二、燃油车真正被雇来做什么

买油车的人，很少在雇「燃烧汽油」。他们在雇一组绑在一起的工作。

**功能上**，它要可靠地把人、孩子、行李从 A 送到 B，城市能开，长途也能开，全国都能加油、都能修。这件事燃油车做了一百多年，做到了几乎隐形——好到你感觉不到它是一份「工作」，直到它做砸。

**拥车上**，它还被雇来把麻烦压住。保养、机油、4S 店、年检、故障灯，越来越像税务。很多人讨厌的不是开车，是养车。

**情感上**，开车时要觉得自己还行：过去靠引擎声和加速，后来越来越平庸。油价波动、环境讨论，则定期提醒你：这份雇佣附带愧疚和不可控。

**社会上**，车仍然是让别人一眼读懂「我是谁」的语言。豪华品牌仍有效，但渐渐像上一套词汇。

燃油车真正难被解雇的，从来不是发动机本身，而是三样东西绑在一起：

1. **习惯**：加油五分钟，不用学新仪式。
2. **基础设施**：加油站密，修理厂密，二手车残值可预期。
3. **身份语言**：开什么车，意味着什么。

谁想替代它，不能只在「驱动形式」上赢。必须在这三样上，让解雇变得划算。

## 三、早期电车为什么雇不成

GM EV1、日产 Leaf、以及更早那些「像家电的电动车」，功能上已经能开。它们失败的 JTBD 原因很清楚：

它们雇你来做「我是个环保的人」，同时把另外几份更硬的工作辞退了——跑得远、开着爽、看起来成功、随时能补能。

用户不是不在乎环境。是**不会为了环境，解雇自己更在乎的那些工作。**

这就是为什么「先做一辆人人买得起的小电动车」在当时走不通。那份工作在当时的处境里是降级：你解雇了油车，同时解雇了面子、远行和补能的确定性。降级的雇佣，发生不了大规模转换。

特斯拉的第一招，是拒绝当「环保车」。

## 四、先把「最大对手」切开

题目如果是「特斯拉怎么成为燃油车最大的竞争和替代对手」，里面有一个没被检验的词：最大。

「最大」至少有五层，不是一回事：

- 心智上，谁重新定义了「好车」该是什么样
- 溢价和豪华市场上，谁把奔驰宝马的客户抢走最多
- 全球单一车型销量上，谁真正压过了 RAV4 这类油车销冠
- 在中国这个最大车市，谁把燃油车的量挖走最多
- 对传统车企估值和战略的威胁上，谁让董事会睡不着

特斯拉在前几层上非常强。在中国的量上，后来常常不是最大——比亚迪才是合资和自主用户换车时最常见的去向。2023 年 Model Y 以约 122 万辆成为全球最畅销车、超过 RAV4，这是电车第一次在「家庭日常 SUV」这份全球最大的功能工作上，把油车销冠拉下来。与此同时，中国新能源渗透率持续升高，把油车从新车的默认选项里挤走的，是整条战线。

所以更准确的说法是：

**特斯拉是「解雇油车不等于降级」这件事的定义者，不是把油车替光的唯一完成者。**

心智上，它是燃油豪华最主要的征服者。量上，尤其在中国，完成替代的是一整个新能源阵营。后面如果不把这两层分开，讲义会重新变成特斯拉神话。

「竞争」和「替代」也要拆开。对宝马奔驰，特斯拉是竞争：同一份「好车」工作，换了一个雇佣对象。对加油站、4S 店、机油保养，它是替代：不同类，做的是同一组相关工作。特斯拉同时干了这两件事。只说「电动替代燃油」，会把两层叠成一层。

## 五、核心处境：日常车是怎样被解雇的

JTBD 禁止用「新精英」这种标签。它要一个能被想象出来的处境。先只看这一个——特斯拉成为「对手」而不是「玩具」的那一刀，切在这里。

**时间：** 大约 2018 到 2023。  
**处境：** 住在城里，有固定车位，能装家用充电桩。这辆车主要跑通勤和周末，偶尔出远门。家里本来有车。这次是换购，或者考虑再买一辆。短名单上原先是 BBA 的入门 SUV、合资中型 SUV，或者「再开两年旧车」。

这不是第一次买车的学生，也不是没有车位的租房族。那两种是另外的处境，结论会反过来。

### 当时真正的竞争集

不是「特斯拉 vs 所有燃油车」，是当时脑子里真实出现过的候选：

1. 再忍一年，继续开现在这辆油车
2. 换一辆新的油车，或丰田本田那种油电混动
3. 换奔驰、宝马、奥迪
4. 买插电混动（后来还有增程）：通勤用电，出门加油
5. 油车留下，再买一辆电车当第二辆
6. 不买了，多用打车

第五项特别重要。特斯拉很多年先赢的不是「把家里唯一的油车换掉」，而是**被雇成第二辆车**。家庭没有解雇油车，只是把「日常通勤」这份工作从油车手里转走。油车还在，负责长途和「万一」。

替代是分步的：先互补，再替换。写成「一锤子把油车换掉」，故事好看，路径是假的。很多人是先开一年第二辆，再在下一次换购时发现：日常那份工作，已经回不去油车了。

### 四股力怎样翻面

**推力：养车开始像税务。**  
4S 店的信息不对称、定期保养、油价波动。车一出厂就开始过时。限购城市还有更硬的推力，但那是下一节的「绿牌工作」，这里先不混进来。

**拉力：试用打死「再忍一年」，成交后每天被雇的是家充。**  
试驾时把人从旧车里拽出来的，通常是加速和静谧——身体先相信，道理后补。成交之后，每天真正被雇佣的不是零百四秒，是家充：晚上插上，早上满电，补能变成睡觉时发生的事，和给手机充电是同一份工作。OTA 则让这辆车在过户之后还继续干活：功能会自己长出来。油车做不到。

环保是加分，很少是主工作。把拉力写成「人们觉悟了」，会看错现场。

**焦虑：续航、冬天、远行、这是不是一家玩具公司。**  
早期电车死在这里。特斯拉用几件事把否决权关掉：续航进入「日常够用、偶尔远行可规划」的区间；超级充电网络加上行程规划，让远行从「不可想象」变成「要计划，但能完成」；碰撞测试和量产数字，把「这能当真车吗」慢慢关掉；路上同款越来越多，社交证明开始替销售说话。

这里有一份关键的**相关工作**（related job）。克里斯坦森强调过：创新常常不是改核心任务本身，而是把核心任务旁边那些让人难受的事做掉。

超充接住的不是「充电」这个动作，是：**行程要能被完成，日常补能不能变成出门办事。** 车企卖的是车；谁把远行和补能接住，谁才有资格被雇成唯一用车。续航焦虑表面是电池参数，本质是旅途这份工作还没被新方案接住。

**习惯：加油只要五分钟。**  
特斯拉没有说服你学会一套苦修式的补能。它把新习惯做得比加油更懒——在能家充的处境里，你甚至更少「专门为能量出门」。改写习惯，而不是对抗习惯。这就是为什么「有没有固定车位」会把市场劈成两半：家充雇得了，习惯能改写；家充雇不了，超充变成每次出门都要办事，旧习惯赢回来。

### 这一刀切在哪

2023 年 Model Y 成为全球最畅销车，超过丰田 RAV4。含义不是「电动车赢了电动车」，是：一台电车第一次在「家庭日常 SUV」这份全球最大的功能工作上，把油车的销冠拉下来。

中国一二线的增换购数据里，奔驰、宝马、奥迪等豪华品牌用户，置换第一去向几乎都是特斯拉。这是特斯拉真正「最大」的位置：燃油豪华的征服者。合资和自主品牌用户换车，第一去向往往是比亚迪。量的替代，主力不在特斯拉。

两份成绩单都是真的。不要用其中一张去冒充另一张。

## 六、另外两份工作：真实，但解释不了上一刀

产品年表人人会背：Roadster → Model S → 超充 → Model X → Model 3 / Y。JTBD 要问的是：每一段被雇来干什么。三份工作必须拆开，不许互相解释。

### 第一份：雇性能豪华

Roadster 和 Model S 证明的是：雇佣一辆电动车，不必解雇「快」和「贵」。

它去抢的不是 Leaf 的客户，是 7 系、S 级、Panamera 的客户。那些人本来就要雇一辆车来完成：我配得上更好的东西；我开车时要有身体上的快感；我不能看起来像在将就。

特斯拉用瞬时扭矩把「快感」做到油车难以日常使用的程度，用极简内饰和一块大屏把豪华从木纹皮革改写成另一种语言。社会层的工作变了：开特斯拉不再只是「我有钱买德系」，也可以是「我站在下一套操作系统上」。

这份工作极其重要。它解释电车为什么开始能进豪华短名单，解释为什么早期车主会变成行走的广告。它**解释不了**后来的百万销量。把「当别人说这车很厉害时，自己心里那点确认」平移到 Model Y 的全球销冠上，是用第一份工作的社会学，去说明第二份工作的规模。那是讲义里最容易写漂亮、也最不该犯的错。

Model X 可以看成同一份工作向家庭的延伸：我要移动孩子，同时仍然是那个看起来没在将就的家长。猎奇的门是社会层的戏剧，真正的雇佣仍是豪华家庭移动。

### 第二份：雇省心的日常车

就是第五节那个处境。Model 3 和 Model Y 干的是这个。价格降到专业人士雇得起，车身变成全球卖得动的城市 SUV，家充和超充把日常和远行接住。成为燃油车体系对手的，是这一份，不是上一份。

邻居有一辆、路上多起来，作用是降低焦虑，不是创造身份。社交证明属于四力里的「减少害怕」，不要写成「人人都在买进步感」。

### 第三份：雇一辆被允许拥有的车

北京摇号、上海牌照、加州 HOV 车道、欧洲碳排放法规和购置补贴。在限购城市，绿牌经常是主工作，驾驶体验是附带的。

这份工作对销量的影响非常大，而且经常被讲成产品洞察。特斯拉吃到了，所有新能源车都在吃。用牌照和补贴解释特斯拉的独特性，会把政策红利写成马斯克的洞察。

三份工作同时存在。看任何一个具体买家，可能叠了两份或三份。分析时仍然要拆：哪一份在主导这次雇佣，哪一份只是顺带。否则所有成功都可以被讲成「他们看见了更大的工作」——那句话不可证伪，就不是分析。

---

## 七、为什么传统车企明明会造车，却接不住这份工作

他们不是不懂电动。他们的组织是按另一套工作定义长出来的。

- **真正的顾客常常是经销商**，不是开车的人。渠道要的是库存、返点、进店保养，和司机要的「少进店」正好相反。
- **利润绑在保养和配件上。** 车越省心，这份财务工作越痛。特斯拉把拥车麻烦做掉，传统报表会先感到威胁。
- **用车型洪水覆盖人口统计：** 三厢、两厢、各种配置表。JTBD 要的是把一份处境里的工作做透，不是用四十个 SKU 去覆盖四十个人群标签。
- **一年一改款充当「新鲜感」。** 软件持续进化不在能力圈里。油车卖的是成交那一刻的配置；特斯拉卖的是成交之后还在发生的进步。
- **补能是石油公司的事。** 车企不拥有「行程被完成」这份相关工作。自己没有一张能打的补能网，电车就还是「油车的工作定义加一块电池」。

所以传统车企早期的电动车，功能层在电气化，雇佣关系没变：还要去 4S 店，还要在配置表里迷路，远行仍然心里没底。用户雇到的还是旧工作，只是油箱换成了电池。

特斯拉反过来：车型极少、直销、自己补能、自己软件。公司形态是围着「用户要完成的那组工作」长的，不是围着「我们擅长的发动机和渠道」长的。直销解雇的是经销商这份中间人工作；结构更简单，解雇的是大量保养工作；OTA 让雇佣关系在成交后继续。这些不是附加功能，是在改雇佣合同。

## 八、JTBD 解释什么，解释不了什么

到这里，镜头的职权必须收住。否则它会变成事后寓言：凡成功，皆因看见了工作。

**JTBD 解释的是转换意愿。** 为什么在那种处境里，有人愿意解雇油车、雇佣特斯拉：功能不降级，拥车麻烦下降，补能习惯被改写，焦虑被关掉。

**它解释不了转换的规模。** 为什么是这家公司、在这个十年、把量做出来。至少还有三件 JTBD 管不到的事：

1. **电池成本曲线。** 没有这一条，电车停在豪华玩具。成本下降是整个产业的事，不是特斯拉发明了「家充这份工作」才出现的。
2. **产能，尤其是上海工厂。** 2019 年后的上海，是特斯拉从「改写了定义的豪华品牌」变成「能打量的对手」的供给条件。洞察没有工厂，还是小众雇佣。
3. **政策。** 双积分、碳排放、限牌绿牌、补贴退坡的节奏，直接改变竞争集里每一项的相对价格。绿牌那份工作，本质上是管制创造的工作。

没有这些，特斯拉仍然可以是懂 JTBD 的公司。它成不了燃油车体系的量级威胁。把洞察写成主因、把供给和管制写成氛围，是把一个镜头当成全能理论。

克里斯坦森说它不是经典破坏，和「它懂待完成的工作」可以同时成立。前者描述的是市场进入路径，后者描述的是用户为什么愿意换。路径是高端维持性创新，雇佣上仍然可以抢走油车的工作——尤其是豪华和日常 SUV 那两层。

## 九、哪些工作特斯拉还没接住

边界比身份故事更重要。正因为 JTBD 看的是处境，它会告诉你：同一家公司，在另一种处境里会输。

**没有固定车位、装不了家充。** 家庭充电这份关键工作雇不了。超充变成每次出门都要办事，四力里的焦虑和习惯回到燃油车一边。这是纯电至今最硬的结构性裂口，不是广告能补的。

**唯一用车，经常长途，补能不可预期。** 油车或增程在「无脑补能」上仍更好雇。你雇的是确定性，不是度电成本。

**只想省油，什么习惯都不改。** 丰田油电混动雇的就是这份零切换工作：还是加油，油耗自己下去。习惯成本接近于零，这是很强的雇佣。

**中国后来的插混和增程。** 不是因为用户没听懂特斯拉的故事。是因为他们要雇的工作，特斯拉接不住：通勤用电（雇纯电那部分），出远门不解雇加油站。理想、比亚迪 DM、各种增程，抢的是「唯一用车且不能只依赖充电」这份工作。在中国的量上，这份折中雇佣挖走的油车，可能比特斯拉的纯电叙事更多。

所以特斯拉成为对手，是因为它先在高影响力的购买里，让「好车」的默认工作集合变成：电、家充、少进店、会自己变好。定义改了，品类才跟着重写。把定义改完之后的量，是所有把总持有成本、补能和牌照做平的车一起挖的。

## 十、下一份工作（还没有成为历史）

有人会把无人驾驶出租车写成特斯拉更可怕的一章：以后不必拥车，只需出门。

从 JTBD 看，那确实是另一份工作——从「雇一辆属于我的车」变成「雇一次被完成的出行」。它竞争的不是发动机，是拥车这份工作本身：贷款、保险、停车、折旧，而车一天停二十多个小时。对「只是要代步」的人，私家车是一份很差的工作。

但这份工作还没有成为特斯拉已经赢过燃油车的原因。它是下一份可能被雇佣的工作，不是回顾「是怎么成为对手」时的高潮。现在把它写成已经完成的替代，会用预言补厚度。能记住的一句就够了：如果有一天出行可以不必拥车，被解雇的将不只是燃油车，而是「家里必须停一辆车」。

## 十一、收束：这套镜头怎么用在别的产品上

把全文压成几句可以带走的话。

燃油车输的不是发动机。是在一种已经足够普遍的处境里——有车位、能家充、车主要用于日常——它能被雇去完成的进步变少了。特斯拉是第一家让这次解雇不必降级的产品：快和贵不必辞退，养车麻烦被重做，补能习惯被改写成更懒，远行被充电网勉强但真实地接住。

早期电车失败，是因为为了环保解雇了更硬的工作。特斯拉先把那些硬工作抢回来，再叠加油车做不了的工作，转换才开始发生。替代往往先以「第二辆车」的形式出现，再在下一次换购里变成替换。

它改的是「好车」的默认工作集合。量是后来整条新能源战线一起挖的。政策、电池成本和工厂决定了挖得有多深。没家充、唯一用车且常长途、只想零切换省油——那些处境里，油车、混动和增程仍然更好雇。

如果只记住一个方法，记住这个，而不是记住特斯拉：

1. 先写处境，不要写人格标签。
2. 列出当时真实的竞争集，包括「再忍一年」和「不买」。
3. 看四股力哪一面还没翻，而不是只把产品功能加长。
4. 把相关工作找出来：核心任务旁边，什么东西让人难受。
5. 标明这个镜头解释意愿，不解释规模。

奶昔的对手是香蕉和无聊。特斯拉的对手，从来不只是别的汽车。是再开一年的旧车、加油站、4S 店、第二辆车的空车位、绿牌、以及后来所有把同一份日常工作做平的电车。谁在那份工作上被雇佣，谁才是对手。品类的名字，是事后才追认的。
