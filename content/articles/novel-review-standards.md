## 维度一：去AI味检测

这是笑来方法论中最核心的部分——识别并删除"AI生成文本"的典型特征。

### 1.1 叠套表达检测

**问题描述**：一个概念被层层叠加修饰，形成嵌套结构，读起来累赘且不自然。

**AI味示例**：
```
❌ 雪花落在土包上已经一层了的雪上，没声音。
❌ 他心里想着过去很久以前发生的事情。
❌ 那个很黑很黑的夜晚。
```

**标准要求**：每个概念只表达一次，避免修饰词叠加。

**质疑理由**：
- 叠套表达是AI生成长句时的典型模式——模型倾向于在前一个修饰基础上继续添加
- 真人写作时会自然拆分，不会形成"已经一层了的雪上"这种结构

**改进意见**：
```
✅ 土包上已经落了一层雪。雪花落在雪上，没声音。
✅ 他想起过去。
✅ 那个黑得伸手不见五指的夜晚。
```

---

### 1.2 泛泛动作检测

**问题描述**：用最常见的动作描写来应对各种情境，缺乏特异性。

**AI味示例**：
```
❌ 他张了张嘴，没出声。
❌ 她心里一惊。
❌ 大家都觉得很奇怪。
❌ 他停顿了一下。
```

**标准要求**：每个角色的每个反应都应有独特的动作描写，不同角色的同一情绪应有不同表达。

**质疑理由**：
- "张了张嘴"是AI描述惊讶/犹豫时的默认表达，过度使用会让所有角色反应雷同
- 真人写作会根据人物性格、情境设计独特反应

**改进意见**：
```
✅ 他的喉结动了一下。（男性特征）
✅ 她手里的杯子晃了一下。（女性特征）
✅ 老张停下了筷子。（老动作特征）
✅ 那女人转过脸往街那头看。（回避型性格）
```

**检测方法**：搜索"张了张嘴"、"心里一惊"、"停顿了一下"等高频泛泛词，统计密度。

---

### 1.3 模糊指代检测

**问题描述**：用"那位"、"这个人"、"他"等模糊代词指代特定人物，增加理解负担。

**AI味示例**：
```
❌ 那位现在很着急。
❌ 这个人的眼神变了。
❌ 他现在只能往上。
```

**标准要求**：用独特特征、关系位置、具体称谓替代模糊指代。

**质疑理由**：
- AI生成对话时倾向于使用模糊指称，避免"说错"
- 真人写作会选择最具区分度的指代方式

**改进意见**：
```
✅ 上头那位，如今也只能往上。
✅ 缺半截指的那只手，始终没离开过腰间。
✅ 顾佳盯着那三个字，看了一会儿。县长的名字。
```

---

### 1.4 冗余收尾检测

**问题描述**：场景结束后添加总结性的环境描写或氛围渲染。

**AI味示例**：
```
❌ ...两人告别，各自离去。
    街上空荡荡的，路灯拉长了影子。
❌ ...她关上了门。
    外面，雪还在下。
```

**标准要求**：场景结束后直接切走，不加任何"氛围尾巴"。

**质疑理由**：
- AI倾向于"完整结束"一个场景，习惯性添加收束句
- 真人写作更信任场景本身的力量，敢于戛然而止

**改进意见**：
```
✅ ...两人告别。
（直接切到下一场景）
```

---

### 1.5 标准化反应检测

**问题描述**：不同角色在相似情境下使用完全相同的表达方式。

**AI味示例**：
```
❌ 人物A张了张嘴，没出声。
❌ 人物B张了张嘴，没出声。
❌ 人物C也张了张嘴，没出声。
```

**标准要求**：每个角色的反应都应有独特性，符合其性格特征。

**质疑理由**：
- AI倾向于复用已有的成功表达模式
- 真人写作会刻意避免重复，为每个人物设计专属动作

**改进意见**：
```
✅ 人物A：喉结动了一下（男性）
✅ 人物B：手里的笔停住了（知识分子）
✅ 人物C：转过头去看窗外（回避型）
```

## 维度二：人物连续性

人物的行为、外貌、特征必须在全文中保持一致。

### 2.1 外貌指纹一致性

**问题检测**：同一人物的外貌特征在不同章节中的描述是否一致。

**质疑理由**：
- V1版本中护士长的发型在第5章是"短发"，第20章变成"盘发"
- 这种不一致会破坏读者的信任感

**改进意见**：
- 建立人物档案，记录所有外貌特征
- 每次涉及该人物时查阅档案
- 修改时统一为一个版本

---

### 2.2 动作签名一致性

**问题检测**：人物标志性动作在不同场景中是否保持一致。

**质疑理由**：
- 笑来在提交中专门修改"顾浩的签名习惯"
- 签名方式是人物性格的体现，必须统一

**改进意见**：
- 确定每个角色的"动作签名"：如"签上名字，日期"
- 在所有相关场景中保持一致
- 通过一致性暗示人物性格

---

### 2.3 语言风格一致性

**问题检测**：人物的说话风格、用词习惯是否前后一致。

**质疑理由**：
- 护士长的语言风格应该是"说话直接、嘴不饶人"
- 如果某个场景中她变得委婉，就破坏了人物塑造

**改进意见**：
- 为每个主要角色定义"语言风格核心"
- 所有对话都围绕这个核心展开
- 删除不符合人物性格的表达

---

### 2.4 行为逻辑一致性

**问题检测**：人物在相似情境下的行为是否符合既定性格。

**质疑理由**：
- 提交"24 陈艺撒谎显代价校准"说明作者关注行为一致性
- 如果一个角色在不同情境下对同一行为的反应不同，需要理由

**改进意见**：
- 定义人物的核心性格特征
- 验证每个关键行为是否符合性格
- 如果不符合，需要有足够的铺垫或解释

---

## 维度三：细节真实度

细节的真实性决定了读者的沉浸感。

### 3.1 职业细节准确性

**问题检测**：职业相关的操作流程、术语、细节是否准确。

**质疑理由**：
- Issue #8读者指出"闭锁综合征"医学描述不准确
- 笑来立即采纳修改，明确"极重型"
- 职业细节错误会破坏专业读者的信任

**改进意见**：
- 用AI搜索职业相关知识
- 请专业人士审核（或通过社区反馈）
- 建立职业细节知识库

---

### 3.2 物品细节真实性

**问题检测**：物品的使用方式、细节描写是否符合现实。

**质疑理由**：
- "往嘴边哈一口气，摁下去"这个印章细节极具真实感
- AI往往缺乏这种生活化的细微动作知识

**改进意见**：
- 为关键操作场景增加"微动作"描写
- 这些微动作是AI难以自动生成的，需要人类补充
- 观察现实生活，积累细节库

---

### 3.3 流程细节完整性

**问题检测**：描述一个流程时，步骤是否完整、顺序是否正确。

**质疑理由**：
- 信访办场景中，笑来增加了"写处理意见→签名→盖章→归档"的完整流程
- 完整的流程让场景可信度大幅提升

**改进意见**：
- 为涉及流程的场景绘制步骤图
- 验证每个步骤的顺序和合理性
- 用AI搜索官方流程文档

---

### 3.4 环境细节连贯性

**问题检测**：环境描写在不同场景中是否连贯，是否有矛盾。

**质疑理由**：
- 如果第10章提到房间朝南，第25章又说朝北，就是矛盾
- 环境细节的错误会破坏空间感

**改进意见**：
- 建立场景档案，记录每个重要空间的位置、朝向、特征
- 涉及该场景时查阅档案
- 修改时保持一致

## 维度四：时间线管理

时间是小说的隐形骨架，必须清晰准确。

### 4.1 时间表达从绝对到相对

**问题检测**：是否过度使用绝对日期，而忽略关系锚。

**质疑理由**：
- "二〇一九年五月四日"对读者意义有限
- "除夕大雪后十六年"更容易让读者定位时间关系

**改进意见**：
```
❌ 二〇一九年五月四日
✅ 二〇一九年五月四日，星期六，五一假的最后一天

❌ 二〇〇三年开春
✅ 除夕大雪后十六年
✅ 那年开春
```

**原则**：用"关系锚"（与事件的关系）替代纯日期，降低记忆负担。

---

### 4.2 跨章节时间同步

**问题检测**：同一时间线在不同章节中的描述是否一致。

**质疑理由**：
- 第11章说"十六年后"，第51章又说"十五年后"，就是矛盾
- 时间线的错误是最容易被读者发现的硬伤

**改进意见**：
- 绘制完整时间轴
- 每次涉及时间时标注在时间轴上
- 修改时检查时间轴，确保一致

---

### 4.3 时间跨度合理性

**问题检测**：事件之间的时间跨度是否合理。

**质疑理由**：
- 如果角色A在第一章是20岁，第十章是25岁，中间只过了"两年"，就不合理
- 时间跨度错误会影响人物成长的可信度

**改进意见**：
- 为每个角色建立年龄档案
- 计算每个时间节点的角色年龄
- 验证年龄与行为、成熟度是否匹配

---

## 维度五：动作与心理

动作替代心理描写是"去AI味"的关键技巧。

### 5.1 心理描写向动作转化

**问题检测**：是否直接告诉读者角色在想什么，而不是通过动作展示。

**质疑理由**：
- 提交"刘莉两处校准（认亲去进脑·告白物里演）"专门删除内心独白
- "李佳心里想着..."是AI最容易生成的模式，也是最有AI味的表达

**改进意见**：
```
❌ 李佳心里认出了顾浩，但她不敢确认。
✅ 她看见那个系鞋带的方法——系成结，捏住两个耳朵打第二道，掖进鞋舌底下。
    系了一辈子。

❌ 她觉得很紧张。
✅ 她的手心全是汗。
```

**原则**：用具体动作替代泛泛心理描写，让读者自己体会。

---

### 5.2 情感通过物品表达

**问题检测**：情感表达是否过度依赖内心独白。

**质疑理由**：
- "告白物里演"——通过物品/动作表达情感
- AI倾向于直接描写情绪，缺乏这种含蓄表达

**改进意见**：
```
❌ 她想起了小时候顾浩给她系鞋带的情景，心里很温暖。
✅ 系了一辈子。（通过"系鞋带"这个细节触发记忆）
```

---

### 5.3 动作特异性

**问题检测**：不同角色的同一情绪是否有不同的动作表达。

**质疑理由**：
- 每个人紧张、愤怒、惊讶的方式都不同
- AI倾向于用标准化动作应对所有情况

**改进意见**：
- 为每个角色定义"情绪反应模式"
- 确保不同角色的同一情绪有不同表达
- 避免所有角色都用"张了张嘴"表示惊讶

---

### 5.4 动作序列合理性

**问题检测**：连续动作的顺序是否合理，是否符合人体工学。

**质疑理由**：
- "拿起杯子→喝了一口→放下杯子"是合理的
- "喝了一口→拿起杯子"就是顺序错误
- AI有时会生成不合逻辑的动作序列

**改进意见**：
- 为关键动作场景模拟实际操作
- 验证动作顺序的合理性
- 修改不合逻辑的部分

---

## 维度六：对话与指代

对话是小说中最容易暴露问题的部分。

### 6.1 对话角色区分度

**问题检测**：遮住名字后，能否区分出是谁在说话。

**质疑理由**：
- 如果所有角色的对话风格都一样，就是失败
- AI倾向于生成"标准对话"，缺乏个性

**改进意见**：
- 为每个角色定义"对话指纹"：用词习惯、句式结构、话题偏好
- 验证每个对话是否符合角色指纹
- 修改不符合的对话

---

### 6.2 代词清晰度

**问题检测**：对话和叙述中的代词是否清晰，是否会造成歧义。

**质疑理由**：
- "他"、"她"、"那位"过度使用会造成理解困难
- "上头那位"比"那位"更清晰

**改进意见**：
- 统计每个段落中的代词密度
- 如果连续使用代词超过3次，考虑替换为具体指称
- 用独特特征替代模糊指代

---

### 6.3 信息密度

**问题检测**：对话中的信息密度是否合理。

**质疑理由**：
- 真人对话往往信息密度低，有很多废话
- AI生成的对话往往信息密度过高，不像真实对话

**改进意见**：
- 为非关键对话增加"废话"：寒暄、重复、犹豫
- 降低对话的信息密度，让它更像真实对话
- 但要注意不能降低可读性

---

### 6.4 潜台词

**问题检测**：对话是否有潜台词，还是所有意思都直接说出来。

**质疑理由**：
- 真人对话往往有大量潜台词
- AI倾向于把意思直接说清楚

**改进意见**：
- 为重要对话设计"双层结构"：表层意思+潜台词
- 用动作、环境描写暗示潜台词
- 不要把所有意思都说出来

---

## 维度七：场景与节奏

场景的转换和节奏控制影响阅读体验。

### 7.1 场景边界清晰度

**问题检测**：场景的转换是否清晰，读者是否能明确知道"这里切换了"。

**质疑理由**：
- 场景模糊会让读者迷失
- AI有时会在同一场景中混合多个时空

**改进意见**：
- 为每个场景定义"边界信号"：空行、分隔符、时间地点标注
- 确保场景转换时有明确信号
- 不要在同一场景中混合多个时空

---

### 7.2 场景完整性

**问题检测**：每个场景是否有明确的目的，是否完整。

**质疑理由**：
- 场景应该有"起承转合"
- AI有时会生成没有明确目的的场景

**改进意见**：
- 为每个场景定义"目标"：传递什么信息、推动什么情节
- 验证场景是否达成目标
- 删除没有明确目标的场景碎片

---

### 7.3 节奏变化

**问题检测**：场景的节奏是否单调，是否有快慢变化。

**质疑理由**：
- 所有场景都用相同节奏会让人觉得累
- AI倾向于生成匀速叙事

**改进意见**：
- 为关键场景设计"快慢变化"：紧张时快、放松时慢
- 通过句子长度、动作密度控制节奏
- 避免匀速叙事

---

## 维度八：伏笔与呼应

伏笔和呼应是小说的高级技巧。

### 8.1 伏笔清晰度

**问题检测**：前期埋下的伏笔是否清晰，读者是否能注意到。

**质疑理由**：
- 伏笔太隐晦会被忽略
- 伏笔太明显又会失去惊喜

**改进意见**：
- 为重要伏笔设计"双重信号"：显性信息+隐性暗示
- 在合适时机提醒读者注意（不要太明显）
- 确保伏笔在后期能被回应

---

### 8.2 呼应完整性

**问题检测**：前期的伏笔是否都有后期呼应。

**质疑理由**：
- "排水检查井线种子补全"——专门为伏笔补全细节
- 未呼应的伏笔会让读者失望

**改进意见**：
- 列出所有埋下的伏笔
- 验证每个伏笔都有呼应
- 删除无法呼应的伏笔

---

## 维度九：职业细节

职业细节是区分专业写作和业余写作的关键。

### 9.1 职业术语准确性

**问题检测**：职业相关的术语是否准确使用。

**质疑理由**：
- "闭锁综合征点名极重型"——这种专业细节很难用AI自动生成
- 术语错误会被专业读者一眼识别

**改进意见**：
- 用AI搜索职业术语的准确定义
- 建立术语表，确保全文一致
- 请专业人士审核（或通过社区反馈）

---

### 9.2 职业流程完整性

**问题检测**：职业相关的流程是否完整描述。

**质疑理由**：
- 信访办的"写处理意见→签名→盖章→归档"流程
- 完整的流程让场景可信度大幅提升

**改进意见**：
- 为关键职业场景绘制流程图
- 验证每个步骤的准确性
- 用官方流程文档作为参考

## 审稿工作流

基于笑来的Git工作流，建议审稿按以下流程进行：

### 步骤1：首次通读（问题收集）

```
目标：建立问题清单

方法：
1. 冷读全文，记录所有"不舒服"的地方
2. 不需要修改，只记录
3. 格式：- [章节]：[位置] [问题描述]（问题类型）
```

**示例问题清单**：
```
- 序曲：雪落一句拆两拍（去叠套）
- 6：信访办那双手头第一次落下去（增加细节）
- 7/42：欲言又止的手势各归其人（去泛泛）
- 51：「上头那位」——所指理清（去模糊）
```

---

### 步骤2：问题分类

```
目标：将问题按维度分类

分类：
1. 去AI味类：叠套、泛泛、模糊、冗余
2. 连续性类：人物、时间、逻辑
3. 细节类：职业、物品、流程
4. 节奏类：场景、节奏、呼应
```

---

### 步骤3：逐一修改

```
目标：每次提交只解决一个问题

格式：重建：[章节] [修改内容]（修改理由）

示例：
重建：58 顾佳台词微调（断言→假设：「如果真死了人」）
重建：31 善后分工写明（何叔送殡仪馆·陈晓伟办医院手续）
```

---

### 步骤4：冷读验证

```
目标：修改后重新审阅

方法：
1. 每完成一批修改，从头冷读
2. 验证修改是否引入新问题
3. 记录新发现的问题
```

## 改进意见示例

### 示例1：开篇场景去叠套

**原文**：
```
雪花落在土包上已经一层了的雪上，没声音。
```

**问题**：
- 叠套表达："已经一层了的雪上"
- AI味明显，读起来累赘

**改进**：
```
土包上已经落了一层雪。雪花落在雪上，没声音。
```

**理由**：
- 拆分成两个短句
- 去除叠套
- 保持意境不变

---

### 示例2：人物反应去泛泛

**原文**：
```
那女人怔在那儿，手里那张折着的单子，捏出了褶。她张了张嘴，没出声，转过脸往街那头看...
马三张了张嘴，没出声。
```

**问题**：
- 两个角色都用"张了张嘴"表示惊讶
- 标准化反应，缺乏区分度

**改进**：
```
那女人怔在那儿，手里那张折着的单子，捏出了褶。她转过脸往街那头看...
马三的喉结，动了一下。
```

**理由**：
- 女人用"转头"表示回避
- 男人用"喉结动"表示紧张
- 增加人物区分度

---

### 示例3：时间表达从绝对到相对

**原文**：
```
二〇一九年五月四日
二〇〇三年开春
```

**问题**：
- 绝对日期对读者意义有限
- 难以建立时间关系感

**改进**：
```
除夕大雪后十六年
那年开春
```

**理由**：
- 用关系锚替代绝对日期
- 降低记忆负担
- 增强代入感

---

### 示例4：指代明确化

**原文**：
```
"那位现在，只能往上。退不得。"
```

**问题**：
- "那位"指代不清晰
- 读者需要回溯才能理解

**改进**：
```
"上头那位，如今也只能往上。退不得。"
```

**理由**：
- "上头那位"比"那位"更清晰
- 增加口语化感觉
- 符合角色身份

---

### 示例5：心理描写向动作转化

**原文**：
```
李佳心里认出了顾浩，但她不敢确认。
```

**问题**：
- 直接告诉读者角色在想什么
- 缺乏画面感，AI味重

**改进**：
```
她看见那个系鞋带的方法——系成结，捏住两个耳朵打第二道，掖进鞋舌底下。

系了一辈子。
```

**理由**：
- 用具体动作替代心理描写
- "系了一辈子"暗示时间跨度和情感深度
- 让读者自己体会，而不是直接告诉

---

### 示例6：职业细节增强

**原文**：
```
顾佳处理完文件，放到一边。
```

**问题**：
- 描述过于笼统
- 缺乏职业细节的真实感

**改进**：
```
桌角还压着昨天剩下的一沓。最上头那件，一个老户，年年来信，年年一样的事。
她翻到末页，在处理意见那一栏写：情况已核实，不属本级受理范围，已按规定答复。
签上名字，日期。抽屉里摸出印章，往嘴边哈一口气，摁下去。

合上，放到旁边那摞里。下一件。
```

**理由**：
- "往嘴边哈一口气"——增加生活细节
- 明确处理流程的每一个步骤
- "年年来信，年年一样的事"暗示工作性质
- 通过重复性工作暗示人物态度

---

### 示例7：场景去冗余收尾

**原文**：
```
...两人告别，各自离去。
街上空荡荡的，路灯拉长了影子。
```

**问题**：
- "街上空荡荡的，路灯拉长了影子"是冗余的氛围尾巴
- AI倾向于"完整结束"一个场景

**改进**：
```
...两人告别。
```

**理由**：
- 场景结束后直接切走
- 不加总结性尾巴
- 让场景本身说话

---

### 示例8：指代关系明确化

**原文**：
```
鲁敬之的枕头里藏着一个本子，记录不多，可每一条都是矿。
```

**问题**：
- "矿"的含义需要读者自己猜测
- 增加理解负担

**改进**：
```
鲁敬之的枕头里藏着一个本子，记录不多，可每一条都是矿。记的都是他头上的人 —— 一笔一笔，压在枕头底下，这么些年。
```

**理由**：
- 立即解释"矿"的含义
- 减少读者的理解负担
- 增强信息传递的效率
