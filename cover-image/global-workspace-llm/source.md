# 全局工作空间：大语言模型的隐性特征方向

> 基于 Anthropic 机械可解释性研究的深度解构

## 省时摘要

现代 LLM 在预训练过程中自发涌现出可被观测的隐性特征方向（J-space）。通过 Jacobian 矩阵分析与激活修补干预，证实该表征向量直接决定最终 Logits 分布，使其具备不依赖文本输出即可完成多步推理的能力。

## 核心概念

- **残差流（Residual Stream）**：现代 LLM 的核心数据载体
- **Jacobian 矩阵**：识别对 Logits 敏感的隐状态方向
- **J-lens**：Anthropic 开发的观测工具
- **激活修补**：通过向量替换验证因果性
- **隐性推理**：模型在残差流中完成多步推理，无需输出文本

## 视觉隐喻

- 神经网络内部空间的可观测性
- 向量流动的隐性路径
- 从显性到隐性的范式转移
- AI 安全的内部干预维度
