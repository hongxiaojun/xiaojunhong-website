# 封面图生成提示词

## 主题
笑来中篇小说《too-late》完整版本对比分析 — Git工作流下的AI辅助创作方法论

## 核心视觉概念
左下角：Git版本树（分支图），抽象表现V1→V2的演进路径
右上角：人机协作符号（简笔人形 + 数字节点），象征AI作为效率放大器
背景：深优雅色调下的文字流/代码流，若隐若现
中心留白：标题区，极简排版

## 视觉元素

### 左下区域 - 版本演进隐喻
- Git分支图的抽象表达：线条从下往上分叉、合并
- 主干（main）向上延伸，v1分支从主干分出、归档
- 线条用优雅的蓝灰色渐变，体现版本流动感
- 可选：在线条节点处标注微小数字（18次提交的隐喻，不必清晰显示）

### 右上区域 - 人机协作
- 简笔人形轮廓（只轮廓，不细致）
- 人形旁边悬浮着数字节点/符号（代表AI）
- 用一条细线连接，象征协作而非替代
- 色调：人形用暖色点缀，节点用冷色，冷暖对比

### 背景层
- 深色基调（深灰/深蓝）
- 若隐若现的文字流或代码片段，半透明，低对比度
- 避免可读的具体文字，保持抽象感

### 中心标题区
- 占据画面中心1/3区域，干净留白
- 中文标题：「《too-late》版本分析」或简化为「too-late版本分析」
- 字体：简洁现代无衬线
- 颜色：白色或浅灰，与背景形成适度对比
- 可选：副标题（极小字号，不抢占视觉）：「Git工作流 · AI写作方法论」

## 色彩方案（Elegant优雅色调）
- 主色：深灰蓝（#2C3E50）作为背景基调
- 强调色1：柔和金/米白（#ECF0F1）用于标题
- 强调色2：淡蓝绿（#1ABC9C）用于版本树线条
- 点缀色：暖橙/金（#F39C12）用于人形协作元素

## 构图原则
- 40-60% 留白（标题区）
- 左下和右上形成视觉平衡
- 版本树和人机协作元素不要太满，保持呼吸感
- 标题居中或略偏上，成为视觉锚点

## 技术风格
- Digital rendering：干净的边缘，现代科技感
- 避免手绘质感或复古滤镜
- 线条利落，色彩过渡平滑
- 整体呈现专业、冷静、有深度的感觉

## 禁止事项
- 不要出现具体的Git命令文本
- 不要出现真实人脸
- 不要过于复杂的图表
- 不要使用高饱和度色彩
- 不要让背景元素干扰标题可读性

## 尺寸
- 宽高比：16:9
- 推荐分辨率：1920×1080 或 1280×720
- 输出格式：PNG
